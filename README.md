## 🖼️ **Vision Gallery**

A beautifully designed **e-commerce art gallery** that brings artwork to life with **smooth GSAP animations**. Built with **HTML, CSS, and JavaScript**, it delivers a **captivating browsing experience** on any device.

### 💡 Features

✅ Fully responsive for all devices

✅ Smooth animations powered by GSAP

✅ Clean and minimal UI

✅ Optimized performance

### 🛠️ Technologies Used

- **HTML**
- **CSS**
- **JavaScript**
- **GSAP (GreenSock Animation Platform)**
